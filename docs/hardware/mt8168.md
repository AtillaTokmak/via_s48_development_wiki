# MediaTek MT8168 SoC Architecture

The **MediaTek MT8168** is a 64-bit quad-core application processor designed specifically for mainstream entry tablets and smart displays.

---

## 1. Core Architecture Details

* **Process Node:** TSMC 12nm FinFET Compact.
* **CPU Complex:** 4x ARM Cortex-A53 cores operating in a single cluster with 512 KB unified L2 cache.
* **Instruction Set:** ARMv8-A (AArch64 / AArch32 compatibility).
* **Clock Management:**
  * Base clock: 500 MHz
  * Stock maximum clock: 2000 MHz (2.0 GHz)
  * Overclocked maximum clock: 2100 MHz (2.1 GHz) via custom device tree OPP table and modified CPUFreq clamping.
* **Dynamic Voltage and Frequency Scaling (DVFS):**
  * Core supply rail: `Vproc` (0.80V to 1.15V) managed by MT6357 PMIC via BUCK converter.
  * Governor: `schedutil` (kernel CFS integration).

---

## 2. Graphics Subsystem

* **GPU:** ARM Mali-G52 MP1 (single core, two execution engines).
* **Architecture:** ARM Bifrost 2nd Generation.
* **API Support:**
  * OpenGL ES 3.2
  * Vulkan 1.1
  * OpenCL 2.0 Full Profile
* **Driver:** In-tree kernel DRM/Kbase `r28p0` driver coupled with user-space Mali user library `libGLES_mali.so`.

---

## 3. Memory & System Interconnect

* **Memory Controller:** Single-channel LPDDR4 / LPDDR4X up to 1600 MHz bus rate (3200 MT/s).
* **Interconnect:** MediaTek AXI crossbar connecting CPU, GPU, Display Processor (DISP/CMDQ), and Multimedia Subsystem (MMSYS).
* **IOMMU:** MediaTek M4U (Media4You) hardware memory virtualization engine managing DMA buffers for display, camera, and video codecs.
